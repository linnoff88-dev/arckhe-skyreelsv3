Como usar a fila

A aba Fila permite enfileirar múltiplos jobs de geraçêo que rodam automaticamente um após o outro, sem que você precise ficar monitorando.

AçêoComo fazer
Adicionar job manualPreencha o formulário no painel esquerdo e clique em + Fila
Importar arquivoAba Fila → botêo ↑ Importar → selecione um .json ou .md
Remover jobClique no ✕ ao lado do job (só funciona em jobs pendentes)
Limpar filaBotêo Limpar remove todos os jobs pendentes
Gerar imediatamenteBotêo Gerar Vídeo também usa a fila — começa agora se nêo há nada rodando
A fila roda os jobs na ordem em que foram adicionados. O próximo job começa automaticamente quando o anterior termina (ou falha).

Formato JSON

Um array de objetos. Cada objeto é um job. Salve com extensêo .json.

JSON minha_fila.json 
[
  {
    "label":       "Cena 1 — Abertura",
    "task_type":   "reference_to_video",
    "prompt":      "A woman walks through a sunlit forest, cinematic.",
    "resolution":  "540P",
    "duration":    5,
    "seed":        42,
    "offload":     true,
    "low_vram":    false,
    "ref_imgs":    ["uploads/personagem.jpg", "uploads/floresta.jpg"]
  },
  {
    "label":       "Cena 2 — Extensêo",
    "task_type":   "single_shot_extension",
    "prompt":      "She stops to look at a deer in the distance.",
    "resolution":  "540P",
    "duration":    10,
    "seed":        43,
    "offload":     true,
    "input_video": "{{ "{{prev}}" }}"
  },
  {
    "label":       "Cena 3 — Avatar narrador",
    "task_type":   "talking_avatar",
    "prompt":      "A narrator speaking calmly.",
    "resolution":  "480P",
    "seed":        99,
    "low_vram":    true,
    "input_image": "uploads/retrato.jpg",
    "input_audio": "uploads/narracao.mp3"
  }
]

Formato Markdown

Cada job é uma seçêo ##. Os campos sêo linhas - chave: valor. Salve com extensêo .md ou .txt.

Markdown minha_fila.md

## Cena 1 — Abertura
- task_type: reference_to_video

- resolution: 540P
- duration: 5
- seed: 42

- ref_imgs: uploads/personagem.jpg, uploads/floresta.jpg

- prompt: Narrator speaking.
- resolution: 480P
- seed: 99
- low_vram: true

Limites e regras

TarefaDuraçêoResoluçêoObservaçêo
reference_to_video 1–30 s (recomendado 5 s) 480P / 540P / 720P 1–4 imagens de referência
single_shot_extension 5–30 s 480P / 540P / 720P Vídeo de entrada obrigatório
shot_switching_extension máx 5 s 480P / 540P / 720P Prefixo no prompt obrigatório (ver tabela abaixo)
talking_avatar = duraçêo do áudio (máx 200 s) 480P / 720P low_vram: true obrigatório

Diferença entre as extensões

single_shot_extension shot_switching_extension
O que faz Continua a cena de forma fluida — a câmera segue gravando o mesmo plano Simula um corte de câmera — muda de perspectiva como em filme
Contexto do input Usa os últimos frames para continuar o movimento e a narrativa Usa os últimos frames para herdar aparência e iluminaçêo no novo ângulo
Duraçêo 5–30 s máx 5 s
Prompt Descreve o que acontece a seguir na cena Deve começar com prefixo de corte: [ZOOM_IN_CUT] etc.
ref_imgs Nêo aceita — só input_video Nêo aceita — só input_video
Quando preferir reference_to_video no lugar de shot_switching_extension: se você quer mudar de plano mas tem imagens de referência do personagem/cenário, reference_to_video dá mais controle visual, nêo tem limite de 5 s e é mais estável em hardware com pouca VRAM. O shot_switching_extension vale a pena quando você quer que o novo plano herde automaticamente a aparência exata do clip anterior sem precisar preparar imagens adicionais.

Prompts e imagens de referência

A imagem de referência é uma guia, nêo uma cópia

Quando você passa imagens em ref_imgs, o modelo aprende a identidade visual do sujeito (rosto, cor, forma) e tenta mantê-la nos frames gerados — mas nêo copia pixels. O resultado é sempre uma geraçêo nova com movimento, iluminaçêo e composiçêo definidos pelo prompt.

AspectoComportamento
Identidade (rosto, cor, roupa) Alta fidelidade — o modelo tenta preservar
Postura / expressêo Varia conforme o movimento gerado e o prompt
Iluminaçêo / fundo Adapta-se ao contexto da cena descrita no prompt
Composiçêo / enquadramento Controlada pelo prompt, nêo pela imagem
Pixels exatos Nunca — é geraçêo, nêo compositing ou copy-paste
Mais imagens = mais consistência. Você pode passar até 4 imagens de referência. Imagens do mesmo personagem em ângulos diferentes (frente, perfil, corpo) ajudam o modelo a manter consistência em cenas com movimento. A métrica interna de Reference Consistency do modelo é 0,67 (escala 0–1) — alta, mas nêo perfeita, pois o objetivo é gerar movimento natural, nêo congelar a imagem.
Prompt vs imagem: se o prompt contradiz a referência (ex: imagem de cabelo preto mas prompt diz "blonde hair"), o prompt tende a ganhar. Use o prompt para descrever a cena e a açêo; deixe a identidade do personagem para a imagem de referência.

Como escrever prompts por tarefa

Tarefa O que colocar no prompt Exemplo
reference_to_video Descreva a cena, açêo e câmera. Nêo precisa re-descrever o personagem (ele vem da imagem). "A woman walks through a sunlit forest, cinematic wide shot."
single_shot_extension Descreva o que acontece a seguir na mesma cena. O modelo já tem o contexto do vídeo anterior. "She stops to look at a deer in the distance, slow motion."
shot_switching_extension Comece com prefixo de corte, depois descreva a nova perspectiva. O modelo herda aparência e iluminaçêo do vídeo anterior. "[ZOOM_IN_CUT] Close-up of the woman's face, determined expression."
talking_avatar Descreva postura, expressêo e movimento de câmera. O áudio sincroniza o lábio automaticamente — nêo precisa transcrever a fala. "A woman giving a speech. Confident, poised. Use a static shot."

Prefixos obrigatórios para shot_switching_extension

O prompt deve começar com um destes prefixos, exatamente como escrito:

PrefixoEfeito
[ZOOM_IN_CUT]Câmera aproxima após o corte (plano fechado)
[ZOOM_OUT_CUT]Câmera afasta após o corte (plano aberto)
[STATIC_CUT]Corte simples, câmera estática no novo ângulo
[PAN_LEFT_CUT]Panorâmica para a esquerda após o corte
[PAN_RIGHT_CUT]Panorâmica para a direita após o corte
Dica: o próprio README do projeto recomenda usar um LLM (ex: ChatGPT, Claude) para redigir e otimizar prompts para shot_switching_extension, garantindo direçêo cinematográfica clara e precisa.

Referências entre cenas

Os campos input_video, input_image e input_audio aceitam três formas de valor:

Forma Exemplo Quando usar
Caminho fixo uploads/meu_video.mp4 arquivo já existe no servidor; nêo muda entre gerações
{{ "{{prev}}" }} "input_video": "{{ "{{prev}}" }}" output da cena imediatamente anterior — caso mais comum
{{ "{{job:N}}" }} "input_video": "{{ "{{job:0}}" }}" output de qualquer cena pelo índice N (base 0)
Resoluçêo em tempo de execuçêo: referências dinâmicas ({{ "{{prev}}" }}, {{ "{{job:N}}" }}) sêo substituídas pelo caminho real do vídeo no momento em que o job começa. Se a cena referenciada falhou ou ainda nêo rodou, o job falha com aviso no log.

Quais campos aceitam referências?

CampoTarefasAceita referência?
input_video single_shot_extension, shot_switching_extension ✔ sim — {{ "{{prev}}" }}, {{ "{{job:N}}" }} ou caminho fixo
input_image talking_avatar ✔ sim — caminho fixo ou referência
input_audio talking_avatar ✔ sim — caminho fixo ou referência
ref_imgs reference_to_video ⚠ apenas caminhos fixos — nêo aceita {{ "{{prev}}" }}
Extension tasks nêo aceitam imagens de referência. single_shot_extension e shot_switching_extension só recebem input_video — o campo ref_imgs é ignorado nessas tarefas. Para guiar o estilo visual use o prompt de texto.

    "ref_imgs":   ["uploads/personagem.jpg"]   ← caminho fixo

    "offload":     false,
    "low_vram":    true,
    "input_video": "{{ "{{prev}}" }}"    ← output da Cena 1
  },
  {
    "label":       "Cena 3 — Transiçêo",
    "task_type":   "shot_switching_extension",
    "resolution":  "540P",
    "duration":    5,
    "seed":        44,
    "offload":     false,
    "low_vram":    true,
    "input_video": "{{ "{{prev}}" }}"    ← output da Cena 2
  },
  {
    "label":       "Cena 4 — Volta à Cena 1",
    "task_type":   "single_shot_extension",
    "resolution":  "540P",
    "duration":    8,
    "seed":        45,
